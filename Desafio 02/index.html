O Workshop | Programação | Formulário | Organização

O HTML na Veia é um evento educacional voltado para iniciantes e entusiastas do desenvolvimento web que desejam compreender, na prática, os fundamentos do HTML. O objetivo é capacitar os participantes a criar páginas web bem estruturadas, acessíveis e alinhadas com boas práticas utilizadas no mercado.

Durante o evento, você aprenderá como organizar conteúdos de forma semântica, construir formulários funcionais e entender a importância do HTML como base para qualquer projeto web moderno. Tudo isso por meio de exemplos práticos, atividades guiadas e troca de experiências com outros participantes.

Se você está dando os primeiros passos na programação ou quer fortalecer sua base para evoluir em CSS, JavaScript e frameworks, este evento foi feito para você.

  • Data: 23/03/2026
  • Local: Poços de Caldas, MG.
  • Publico-alvo: Iniciantes, entusiastas e público em geral.

Programação do Evento

Atividade 1 - Fundamentos do HTML

Horário: 09:00 - 10:30

Descrição:

Introdução aos conceitos essenciais do HTML,incluindo a estrutura básica do documento, principais tags semânticas e boas práticas para organização do código. Ideal para quem está começando e quer entender como a web é construída desde a base.

Atividade 2 - Criando formulários na prática

Horário: 11:00 - 12:30

Descrição:

Aprender a criar formulários completos e funcionais, utilizando campos de entrada, labels, validações básicas e agrupamento de informações. A atividade foca em usabilidade, acessibilidade e na correta coleta de dados do usuário.

Atividade 3 - Projeto final: Sua Primeira Página Web

Horário: 14:00 - 16:30

Descrição:

Hora de colocar a mão na massa! Os participantes irão desenvolver uma página HTML completa, aplicando tudo que foi aprendido durante o evento. Ao final, você terá um projeto estruturado e pronto para receber estilos e interatividade.
